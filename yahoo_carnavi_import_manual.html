Yahoo! マップ / Yahoo! カーナビ　への地点一括登録マニュアル

Windows PC で 28 件の地点を効率よく登録し、 iPhone の Yahoo! カーナビ / Yahoo! マップですぐに使えるようにするための全手順です。
各ステップの下にあるチェックボックスにチェックを入れながら進めれば、迷わず最後まで完了できます。

この作業の仕組み（まず知っておくこと） Yahoo! の「登録スポット」機能は、 Yahoo! 地図（ PC ブラウザ）・ Yahoo! マップ（スマホアプリ）・ Yahoo! カーナビ（スマホアプリ）の三つで共通のデータです。同じ Yahoo! JAPAN ID でログインしてさえいれば、どこか一ヶ所で登録した地点が自動的に他の二つにも反映されます。ログインを両方の端末・アプリで揃えることが今回の作業でいちばん重要なポイントになります。

🔋 0. 事前準備（インストールとログイン）

今回の作業は「同じ Yahoo! JAPAN ID でログインする」ことが土台になります。まずアプリを揃え、ログインまで済ませてください。

  1. iPhone の App Store で「 Yahoo! カーナビ」を検索してインストールします。 Yahoo! JAPAN が提供している無料のカーナビアプリです。
  2. 続けて「 Yahoo! マップ」を検索してインストールします。 地点の検索・登録・整理を行うための地図アプリです。今回はこのアプリで約 30 件を登録します。
  3. Yahoo! カーナビを起動し、メニューから Yahoo! JAPAN ID でログインします。 まだ Yahoo! JAPAN ID を持っていない場合は、この画面から新規作成できます。 登録スポットの共有は Yahoo! JAPAN ID 単位で行われます。ログインしていない状態では、 PC で登録した地点がスマホ側に表示されません。
  4. Yahoo! マップも起動し、同じ Yahoo! JAPAN ID でログインします。 Yahoo! カーナビと Yahoo! マップで、必ず「同一の」 Yahoo! JAPAN ID を使ってください。別の ID でログインすると、地点が共有されません。

💻 ステップ 1 ： Windows PC での一括登録

PC のブラウザ版「 Yahoo! 地図」を使い、キーボードで検索しながら約 30 件をテンポよく登録します。スマホで 1 件ずつ入力するより速く進められます。

  1. PC のブラウザ（ Google Chrome や Edge など）で「 Yahoo! 地図」にアクセスします。 アドレスバーに次の URL を直接入力するのが確実です：
    https://map.yahoo.co.jp/
  2. 画面右上（または左上）にある「ログイン」をクリックし、ステップ 0 と同じ Yahoo! JAPAN ID でログインします。 ここで別の ID を使ってしまうと、せっかく登録した 30 件が iPhone 側に一切表示されません。ログインしているアカウント名を画面で確認してから次に進んでください。
  3. 画面上部の検索窓に、登録したい 1 件目の地点情報（住所・施設名など）を入力して検索します。
  4. 検索結果の一覧、または地図上のピンをクリックし、詳細情報の中にある「登録する」（お気に入り登録のボタン、星やハートのアイコンの場合もあります）をクリックします。 見当たらない場合は、地点名の周辺に表示される星マーク・オレンジ色のボタンを探してください。
  5. 登録先のグループを選ぶ画面が出た場合は、わかりやすいグループ名（例：「よく行く場所」など）を選択、または新規に作成して保存します。 グループ分けしておくと、あとで Yahoo! マップ・ Yahoo! カーナビ側で一覧を見返すときに探しやすくなります。グループ分けが不要であれば「未分類」のままでもかまいません。
  6. 手順 3 〜 5 を繰り返し、目的の約 30 件すべての地点を登録していきます。 1 件登録するたびに検索窓の文字を消して、次の地点を検索してください。焦らず 1 件ずつで大丈夫です。 似た名前の施設が複数出てきた場合は、住所や地図上の位置を見比べて正しい方を選んでください。
  7. 登録が終わったら、画面左側（または上部メニュー）の「登録スポット」「お気に入り」といった一覧画面を開き、約 30 件が正しく登録されているか数を数えて確認します。 件数が合わない場合は、抜けている地点だけ手順 3 〜 5 を繰り返して追加してください。

📱 ステップ 2 ： iPhone での反映確認

PC で登録した地点は、同じ Yahoo! JAPAN ID でログインしていれば自動的に iPhone 側にも反映されます。ここでは「確かに反映されているか」を確認するだけです。

  1. iPhone で「 Yahoo! マップ」アプリを開きます。 すでに起動していた場合は、一度アプリを完全に閉じてから開き直すと確実です。
  2. 画面下部のメニューから「登録済み」「登録スポット」など、保存した地点の一覧を表示する項目をタップします。
  3. PC で登録した約 30 件の地点が、そのままリストに表示されていることを確認します。 表示されない場合は、 Yahoo! マップのログイン中アカウントがステップ 0 ・ 1 と同じ Yahoo! JAPAN ID になっているか、設定画面またはメニューから再確認してください。ログインアカウントが違っていることが最もよくある原因です。
  4. 件数や中身に問題がなければ、続けて「 Yahoo! カーナビ」アプリも開き、同様にメニュー内の登録スポット一覧に約 30 件が表示されていることを確認します。 Yahoo! マップと Yahoo! カーナビは同じ登録スポットのデータを共有しています。片方で確認できれば、もう片方でも基本的に同じ内容が見えます。

🚗 ステップ 3 ： Yahoo! カーナビでの目的地設定

実際に車に乗る際、登録スポットの中から目的地を選んでナビを開始する手順です。この操作は使いたい地点ごとに毎回行います。

  1. iPhone で「 Yahoo! カーナビ」アプリを開きます。
  2. 画面上部の検索窓のすぐ下（または検索窓をタップした際の候補欄）にある「登録スポット」をタップします。
  3. 表示された一覧の中から、目的地に設定したい地点をタップします。 グループ分けしてある場合は、グループ名で絞り込んで探すと見つけやすくなります。
  4. ルート候補が表示されるので、希望のルートを選択し、「ナビ開始」をタップします。 目的地が正しいか、画面上で一度確認してから走行を始めてください。

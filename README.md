# 作成文書（ A Reading Room ）

時事の検討、企業・製品の調査、手順書、実務記録、比較資料など、 45 本の日本語の HTML 文書を集めたサイトです。個々の文書を読むだけでなく、節ごとに整理した一覧から探せます。本文検索も使えます。

文書の一覧は [`portal.html`](portal.html) です。八つの節から文書を選べます。

公開サイトのトップに置いてある [`index.html`](index.html) は、文書の一覧ではなく、動きのある装飾ページです。

## ローカルで読む

`portal.html` をブラウザーで開くと、そのまま閲覧できます。ただし、本文検索は文書を実行時に取得するので、ファイルを直接開くと動きません。検索を使うときは、プロジェクトのルートで次のコマンドを実行してください。

```sh
python -m http.server 8000
```

ブラウザーで <http://localhost:8000/portal.html> を開きます。

## ファイル構成

```text
.
├── index.html                # 公開サイトのトップ（装飾ページ）
├── portal.html               # 文書の一覧（本文検索つき）
├── README.md                 # プロジェクトの案内
├── CLAUDE.md                 # 作業指示（文書の意匠は Claude Code のスキルを正とする）
├── future-article-themes.md  # 現状の整理と、次に書く文書のテーマ候補
├── public_URL.txt            # 公開 URL とリポジトリ URL（Git 管理外）
└── *.html                    # 各文書（ index.html と portal.html を除き 45 本）
```

文書はそれぞれ独立した HTML ファイルです。一覧から各文書へ相対リンクで移動できます。ビルド工程や外部依存はありません。

## 技術

- HTML と CSS による静的サイト
- ビルドツール、外部ライブラリ不要
- JavaScript は、 `portal.html` の本文検索だけに使用

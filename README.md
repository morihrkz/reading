# 作成文書（ A Reading Room ）

時事の検討、企業・製品の調査、手順書、実務記録、比較資料など、 32 本の日本語の HTML 文書を集めたサイトです。個々の文書を読むだけでなく、節ごとに整理した一覧から探せます。本文検索も使えます。

## 公開ページ

文書の一覧は [`portal.html`](portal.html) です。六つの節から文書を選べます。

| 節 | 内容 |
| --- | --- |
| 時事・政治・経済・国際 | 日本の大型選挙の日程、中道改革連合の解体後の動き、新築マンションの価格と購入者、ノルウェーの石油をめぐるファクトチェック、国際刑事裁判所所長への米国の制裁、米国政治 |
| 企業・ IT ・産業の調査 | Software AG 、 Adabas 、 Essbase の来歴、クラウド市場の構造分析、 MacBook Pro と Windows PC の差 |
| FPV ドローンと周辺機器 | マニューバの仕組みと語の来歴、 DJI のマニュアルモード、 FPV シミュレータ、 Handlebar RC の輸入 |
| 暮らし・健康・教養・スポーツ | タイヤのサイズ、五十肩とサイレントマニピュレーション、社会的比較と年齢、哲学の独学、日本探偵小説の三大奇書、ブルージェイズの 2026 年シーズン |
| 手順書・計画書・実務記録 | ahamo への変更、 Yahoo! カーナビへの地点登録、シャットダウンの設定、 Claude Code の環境移植、静的サイトの移行、 EmDash 入門、 Suno MCP の接続 |
| 資料・見本 | 生成 AI 企業の比較、国内の経済圏の構成、 HTML の dl ・ dt ・ dd タグの解説、配色見本 |

公開サイトのトップに置いてある [`index.html`](index.html) は、文書の一覧ではなく、動きのある装飾ページです。

## ローカルで読む

`portal.html` をブラウザーで開くと、そのまま閲覧できます。ただし、本文検索は文書を実行時に取得するので、ファイルを直接開くと動きません。検索を使うときは、プロジェクトのルートで次のコマンドを実行してください。

```sh
python -m http.server 8000
```

ブラウザーで <http://localhost:8000/portal.html> を開きます。

## ファイル構成

```text
.
├── index.html                # 公開サイトのトップ（装飾ページ）
├── portal.html               # 文書の一覧（本文検索つき）
├── README.md                 # プロジェクトの案内
├── CLAUDE.md                 # 作業指示（文書の意匠は Claude Code のスキルを正とする）
├── future-article-themes.md  # 現状の整理と、次に書く文書のテーマ候補
├── public_URL.txt            # 公開 URL とリポジトリ URL（Git 管理外）
└── *.html                    # 各文書（ index.html と portal.html を除き 32 本）
```

文書はそれぞれ独立した HTML ファイルです。一覧から各文書へ相対リンクで移動できます。ビルド工程や外部依存はありません。

## 技術

- HTML と CSS による静的サイト
- ビルドツール、外部ライブラリ不要
- JavaScript は、 `portal.html` の本文検索だけに使用

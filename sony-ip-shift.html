企業史・コンテンツ産業論

ソニーはなぜ IP の会社になったのか
――トリニトロンの時代から『鬼滅の刃』の時代へ

From Cathode-Ray Tubes to Characters: The Long Shift of a Hardware Maker Toward Intellectual Property

2008 年 3 月、ソニーは世界で累計 2 億 8,000 万台を販売したブラウン管「トリニトロン」の生産から撤退した。 [1] それから十数年を経た現在、同社を支える看板の一つは、テレビではなくアニメ作品である。かつて「画質の会社」と呼ばれた企業が、なぜ、どのような順序で「 IP の会社」へと軸足を移したのか。本稿は、 IP ビジネスの基本構造を押さえたうえで、その経緯を 1968 年から現在までたどる。

【方法と限界】公開されている報道・資料にもとづく整理であり、各時点での経営判断の動機を社内資料で裏づけたものではない。動機や因果に踏み込む箇所は「と考えられる」と明示した。また、ソニーは現在もエレクトロニクスを手がける企業であり、「テレビから IP へ」は事業の重心の移動を指す表現であって、ハードウェアからの全面撤退を意味しない。

1. 前提――IP ビジネスとは何か

IP ビジネスとは、漫画・アニメ・ゲーム・小説・キャラクターといった創作物の権利を第三者に許諾し、多角的な展開によって収益を最大化するモデルである。かつては「一つの作品を売る」だけだったものが、現在は「一つの世界観やキャラクターを土台に、多様なメディアと商品へ派生させる」形に進化している。収益源は、グッズ化などのライセンス、アニメ化・映画化・ゲーム化といったメディアミックス、海外の配信や現地展開、ライブやコラボカフェなどのファン向けイベントの四つに大別できる。

なぜ今、これが重視されるのか。理由は二つある。第一に、ゼロから新しいヒット作を生むのは難度が高く投資リスクも大きいが、認知度とファンを持つ IP があれば、新作の企画にも最初から一定の集客を見込める。第二に、優れた IP は世代を超えて愛されるため、 10 年、 20 年という長期にわたって安定した収入をもたらす。つまり IP は、一度きりの商品でなく「持続可能な資産」として扱われる。

この二つの性質、とりわけ「資産として長持ちする」という性質を、ソニーがかつて主力としていた事業と並べてみると、同社の選択の意味が見えてくる。

2. トリニトロンが築いたソニー

トリニトロンは、 1967 年に開発され、 1968 年に製品化されたブラウン管の方式である。アパーチャーグリル方式という独自の構造を持ち、世界累計の販売台数は 2 億 8,000 万台に及ぶ。ピークの 2000 年には単年で 2,000 万台を販売した。 [1] ここまでの数字だけを見れば、これは企業の屋台骨と呼ぶにふさわしい。

ただし、この種の資産には構造的な弱点があった。技術の優位は、別の技術が登場すれば一世代で失われる。ブラウン管の優劣をどれほど磨いても、市場が液晶やプラズマに移れば、積み上げた技術は値打ちを失う。「製品を売る」商売は、売った瞬間に次の製品との競争が始まるからである。

これは、前節で見た IP の性質――世代を超えて収益を生み続ける資産――の、ちょうど裏返しにあたる。

3. 技術の会社が「中身」を買った

ソニーは、その弱点に早くから無自覚だったわけではないと考えられる。同社は 1968 年に米 CBS との合弁で CBS ・ソニーレコードを設立し、音楽という「中身」の事業に足を踏み入れていた。そして 1988 年に米 CBS レコードを約 20 億ドルで、 1989 年に米コロンビア・ピクチャーズを約 34 億ドルで買収する。 [2] これらは現在、ソニー・ミュージックエンタテインメントとソニー・ピクチャーズエンタテインメントに引き継がれている。

買収の論理は、ハードとソフトの両輪を持つという発想にあったと考えられる。再生機器を売るだけでは、規格や技術の競争に巻き込まれ続ける。映画や音楽の権利そのものを持てば、機器の勝敗とは別に、作品が収益を生む。この発想は、 IP が「資産」だという現在の説明と、ほとんど同じ構造をしている。

もっとも、 1980 年代末の時点では、これはまだ「ハードの付加価値を高めるための補完」という位置づけにとどまっていた。軸足そのものは、依然としてブラウン管にあった。

4. ゲームという第三の柱

転機の一つは、 1991 年にある。ソニーは任天堂とスーパーファミコン向けの CD-ROM 機を共同開発していたが、 1991 年の CES に試作機を出展した直後、任天堂が別の企業との提携を発表し、共同開発は中止となった。単独での参入を決めたのは、当時の経営トップだった大賀典雄氏とされ、開発は久夛良木健氏が主導したと伝えられている。 [3] ソニー・コンピュータエンタテインメントが 1993 年に設立され、初代プレイステーションは 1994 年 12 月 3 日に発売された。 [3][4]

この出来事の意味は二重にある。まず、提携の破談という外的な事情が、結果として自前のプラットフォームとソフト供給網の構築につながった。ゲーム機は、ハードを売る事業であると同時に、ソフトのライセンスで収益を得る事業でもあるからである。次に、ここでソニーは初めて、自社の技術を、自社が権利を握る作品の流通と結びつけた。のちの IP 戦略の原型が、ここに見える。

5. トリニトロンの終幕

一方、本業のテレビでは、潮目の変化に対応が遅れた。 2008 年 3 月末、ソニーはトリニトロンの生産から撤退する。国内の販売は前年に終えており、最後に残っていたのは、中南米向けに出荷していたシンガポール工場の生産だった。報道は、平面トリニトロンを搭載した「ベガ」シリーズの成功が、液晶テレビへのシフトを遅らせたと伝えている。 [1]

ここには皮肉がある。ブラウン管で最も成功した製品が、次の技術への移行を最も難しくした。成功した技術への投資が大きいほど、それを捨てる決断は重くなるからである。先に述べたとおり、技術の優位は一世代で失われる。その性質が、最も顕著な形で表れた事例といえる。

本稿は、ソニーが「テレビを捨てて IP に転じた」とは主張しない。時系列を見れば、 IP 関連の事業は 1960 年代末から並行して育てられており、テレビ事業の不振が、その比重を相対的に高めたと整理するのが実態に近い。

6. アニメ IP を束ねる

2020 年代に入ると、重心の移動は、とりわけアニメで鮮明になった。中心にいるのは、ソニー・ミュージックグループ傘下のアニプレックスである。同社は『鬼滅の刃』をプロデュースし、配給と海外展開も手がける。『鋼の錬金術師』（ 2003 年）がヒットするまでは赤字だったとされ、報道では「ソニーグループにとってのピクサー」とも評されている。 [5]

2021 年には、ソニー傘下の Funimation Global Group が、米 AT&T から配信大手のクランチロールを 11 億 7,500 万ドルで買収した。 Funimation は、ソニー・ピクチャーズエンタテインメントとアニプレックスの合弁事業である。 [6] これにより、制作（アニプレックス）、配信（クランチロール）、映画・音楽・ゲームという周辺事業が、同じグループの中でつながった。

この体制は、冒頭で見た IP ビジネスの展開モデル――原作創出、認知拡大、多角化――を、一つの企業グループの内部で完結させる設計だと読める。成果も数字に表れている。劇場版『鬼滅の刃』無限城編は、全国約 590 館のうち 443 館で初日公開され、公開 5 週目までの興行収入は 257 億円、観客は約 2,000 万人に達した。上映は 80 以上の国・地域で決まっている。 [5] アニプレックスの 2022 年 3 月期の売上高も 1,790 億円、営業利益は 362 億円に上った。前期に『無限列車編』が大ヒットした反動で減収減益となった年でも、この規模である。 [7]

7. 変わったもの、変わらなかったもの

ここまでの経緯を、年表にまとめる。

時期出来事IP への軸足移動という観点での意味
1968 年トリニトロン製品化。 CBS ・ソニーレコード設立主力の技術事業と、音楽という「中身」の事業が並行して始まる
1988 〜 1989 年米 CBS レコード、米コロンビア・ピクチャーズを買収音楽・映画の権利そのものを大規模に保有する
1993 〜 1994 年ソニー・コンピュータエンタテインメント設立、プレイステーション発売自社プラットフォームとソフト供給網の構築
2000 年トリニトロン、単年販売がピーク（ 2,000 万台）ブラウン管事業の頂点であり、転換の始まりでもある
2008 年トリニトロン生産終了ハードの優位が一世代で失われたことの象徴
2021 年クランチロール買収アニメの制作から配信までをグループ内でつなぐ

この年表から読み取れるのは、「テレビメーカーが突然 IP に転じた」という物語ではなく、三十年以上にわたる、複数の事業の並走と比重の移動である。変わったのは、収益の源泉の置き場所だった。優れた画面を作る技術から、人が繰り返し観たくなる作品へ。前者は一世代で陳腐化するが、後者は IP として 10 年、 20 年と収益を生み続けうる。企業の持続性という観点から見れば、この移動は合理的だったと考えられる。

では、変わらなかったものは何か。それは「規格や画質の優劣ではなく、体験の質で選ばれる」という、ソニーの出自である。ブラウン管の時代には色の美しさが、アニメの時代には物語とキャラクターが、その役割を担っている。技術の会社から IP の会社へ、というよりも、「人が価値を感じる体験を、長く届け続ける会社」への一貫した移行だったと見ることもできる。

IP が単なる「作品」でなく「戦略的資産」だとすれば、ソニーの 50 年は、その資産の置き場所を探し続けた歴史と言い換えられる。そして『鬼滅の刃』は、その探索がひとまず結実した姿である。

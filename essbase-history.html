Essbase の来歴

作成日 : 2026-10-21 ／ 種別 : 調査結果のまとめ ／ 調査方法 : Web 検索と公開記事の確認

結論 : Essbase の開発・販売元は米国の Arbor Software （アーバー・ソフトウェア）で、 1992 年に初版を出した。
1998 年に Hyperion Software と合併して Hyperion Solutions となり、製品名は Hyperion Essbase になった。
2007 年に Oracle が Hyperion を買収し、現在は Oracle Essbase である。

1. 要点

  • Essbase は多次元データベース (MDBMS) で、表計算ソフトの規模の限界を超えるために作られた。
  • 生みの親は Arbor Software 。 1992 年に初版を出荷し、同年に多次元データの格納・検索方法の特許を出願、 1994 年に成立した。
  • 1998 年 8 月に Hyperion Software と合併し、 Hyperion Solutions になった。 Essbase は合併後の OLAP 製品群の中心に据えられた。
  • IBM は 2005 年末ごろまで、 Essbase の OEM 版を「 DB2 OLAP Server 」として販売した。
  • 2007 年 4 月、 Oracle が約 33 億ドルで Hyperion を買収した。

3. 1998 年の Arbor と Hyperion の合併

1990 年代後半の Essbase を語るうえで最大の出来事は、この合併である。 Hyperion Software は、財務連結・予算管理などの業務アプリケーションを持つ会社で、前身は 1981 年創業の IMRS だった。 Arbor は OLAP エンジンの Essbase を持つ会社で、両者は補完関係にあった。

項目内容
株式の交換Hyperion Software の普通株 1 株につき、 Arbor 株 0.95 株。持分プーリング方式
持株比率Hyperion 側の株主が約 60% 、 Arbor 側が約 40%
売上（ 1998 年度）Hyperion Software 約 2.95 億ドル、 Arbor 約 0.82 億ドル、合計約 3.75 億ドル。従業員は 1,800 人超
製品の方針Arbor Essbase を Hyperion Essbase に改名。予算管理の Hyperion Pillar 、連結の Hyperion Enterprise と統合。既存の Hyperion 製 OLAP の顧客には Essbase への移行を促す
当時の評価Hurwitz Group は、 OLAP 市場で Oracle をわずかに上回る首位になると評した。一方で、 Essbase を Pillar や Enterprise に組み込む際の後方互換性と、株主からの早期の成果要求をリスクに挙げた

4. Essbase の技術の特徴

多次元モデル

データを「ハイパーキューブ」として持つ。地域別・製品別・期間別などの切り口ごとに表計算のシートを複製する運用をやめ、一つのモデルに集約する発想である。

疎な次元と密な次元

ブロック格納方式では、開発者が各次元を「密 (dense) 」か「疎 (sparse) 」に指定する。データが実在する組み合わせにだけ記憶領域を割り当てるため、大半が空になる多次元データを効率よく持てる。

計算とインターフェース

階層の集計、保存された計算メンバーと動的な計算メンバー、手続き型の計算スクリプトを備える。 C 、 Visual Basic 、 Java の API があり、利用者は主に Microsoft Excel のアドインから使う。 7 版でブロック格納 (BSO) に加えて集計格納 (ASO) が入り、後者では MDX で動的計算を書く。

5. 1990 年代の日本での販売について

結論 : 1990 年代の日本での販売会社は、今回の調査では特定できなかった。 Arbor Software が日本に自社の拠点を持っていた形跡も、見つからなかった。ただし、販売経路をたどる手がかりは三つ見つかった。

手がかり 1 : Arbor 自身の拠点に日本がない

米国証券取引委員会 (SEC) に出された Arbor の年次報告書（ 1997 年 3 月期と 1998 年 3 月期）に、日本という語は出てこない。子会社は英国・フランス・ドイツにあり、 1997 年 3 月期の報告書に、パリ、フランクフルト、ハンブルク、ミュンヘン、シドニーに拠点を開いたと書かれている。販売地域は「米国、カナダ、欧州、環太平洋」で、海外売上は 1997 年 3 月期で全体の 11% 、その大半は欧州だった。このため、日本での販売は、自社の直販ではなく、他社を通じた間接販売が中心だったと考えられる（推論）。

手がかり 2 : 間接販売の提携先に日本企業が載っている

提携先報告書での記載日本との関係
富士通1997 年 3 月期の報告書（修正版）と 1998 年 3 月期の報告書の両方で、間接販売の提携先として名が挙がる日本の企業だが、日本での販売を担ったとは書かれていない
三菱商事1998 年 3 月期の報告書（ 1998 年 6 月 10 日提出）で、販売提携先として名が挙がる同上。役割（ OEM 、再販業者、販売代理店のどれか）も書かれていない
Comshare最大の再販業者で、 1996 年 3 月期の売上の 26% を占めた。 Essbase を世界で使い、複製し、再許諾する権利を持つ日本での活動は確認できず

手がかり 3 : 日本法人は合併後に現れる

合併後の Hyperion Solutions については、 2001 年 2 月に Hyperion Solutions Japan の社長に就いた人物の経歴が確認できた（その人物は 1998 年 2 月に米国の Hyperion Solutions に入社している）。したがって、少なくとも 2001 年には日本法人があった。 Essbase 7.1 の日本語版は 2004 年に出荷が発表されている。設立の時期と、 1990 年代の Arbor 時代との関係は確認できなかった。

補足 : Comshare との争い

Comshare は Essbase を自社の販売網でも売っていたが、 Arbor との間でライセンスをめぐる争いが起き、 1996 年に仲裁の手続きが始まった。 1997 年の報告書でも訴訟中とされている。 Comshare の Essbase 関連の売上の約 50% から 60% は海外の顧客向けだったが、その中に日本が含まれるかどうかはわからない。

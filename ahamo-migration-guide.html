最初に

  • お店でできること。ドコモショップでは、有料の「 ahamo WEB お申込みサポート」（税込 3,300 円）を受けられます。ただし、申し込みの操作をするのはご自身です。お店の人は、画面を見ながら必要に応じて案内する役です。代わりに操作してくれるサービスではありません。受け付けは店舗ごとに電話で確認してください（第 7 章）。
  • お店でできないこと。契約後の相談はお店では受けられず、 ahamo に変更したあとの手続きは、ドコモショップなどではできません（WEB または郵送）。開通は、ご自身で行う流れです（出典 1 ・ 2 ）。機種変更を同時に申し込むこともできません。
  • d 払い・ iD 。 ahamo の公式案内では、変更後も続けて使えます。ただし、残高が一時的に 0 円と表示される、「ドコモメール持ち運び」を申し込まないとドコモメールが使えなくなるなど、事前に知っておくことがあります（第 5 章）。
  • 行く場所と回数。お店に行くのは、申し込みの日が中心です。何回行くことになるかは、確認できていません。お店で確認してください。

1全体の流れ

手続きは、三つの場面に分かれます。「前日」と「後日」は自宅、「当日」はお店です。

  1. 前日・自宅で
    • 契約内容を確認する
    • d アカウントで入れるか試す
    • お店の来店予約をとる
  2. 当日・お店で
    • お申込みサポートを頼む
    • 操作は自分、店員は案内役
    • 費用は 3,300 円
  3. 後日・自宅で
    • SIM / eSIM を自分で開通
    • d 払いと iD を試す
    • 請求とメールを確認する

1.1 お店でのお手伝いと、自分でする場合を比べる

「お店で手続きしたい」という望みに最も近いのは、お申込みサポートを使う方法です。ほかの方法も、同じ観点で並べます。

4お店に行く日

4.1 予約

各店舗の公式ページには、「店頭来店」の予約、オンライン来店（ビデオ通話）の予約などが載っています。 d アカウントでログインして予約する方法もあります（出典 9 ）。お申込みサポートに予約が必須かどうかは、確認できていません。助言 : 電話で「お申込みサポートを受けたいが、予約は必要か」と聞いてください。理由は、待たずに済むか、書類や持ち物の確認ができるからです。

4.2 当日の流れ

  1. 受付で、来店予約をしていれば、そのことを伝えます。受付が終わる時刻は、営業時間の終わりより早い店舗があります（例 : 荻窪タウンセブン店は受付が 19:00 まで。出典 9 ）。時間に余裕をもって行ってください。助言
  2. 次の言葉で、用件を伝えます。
    「 ahamo への変更を、お申込みサポートで手伝ってほしいです。」
    （機種変更をしない場合）「機種変更はしません。今の端末のまま使います。」
    「 d 払いと iD を、変更のあとも使いたいです。」
  3. 自分の端末で、 ahamo サイトの画面を進めます。分からないところは、お店の人に質問します。お店の人は、画面を見て必要に応じて案内する役です（出典 1 ）。
  4. 内容と注意事項は、ご自身で読んで確認します。お店の人に説明の義務はありません（出典 1 ）。 3,300 円の支払い方法は、確認できていません。店舗で聞いてください。
  5. 申し込みが終わったら、 SIM ／ eSIM の届き方と、開通の方法を確認します。
新規契約には審査があり、お申込みサポートを使っても契約が成立するとは限らないと案内されています（出典 1 ）。ドコモからのプラン変更でも同じかは、確認できていません（要確認）。

5d 払い・ iD を使い続けるために

公式の案内では、「 d 払い・ iD をご利用いただけます。ドコモから ahamo に変更後も継続してご利用いただけます」とされています（出典 10 ）。ただし、次の違いがあります。

変わらないもの

  • d 払いと iD は使える
  • d アカウントは引き継げる
  • 合算払いの限度額は同じ

変わる・注意

  • d 払い残高が一時 0 円に見える
  • 持ち運びなしだとメール失効
  • Amazon の d 払いは再設定

確認が必要

  • 使っている iD の種類
  • iD アプリの設定
  • 店頭か公式で確かめる

6手続きのあとにすること

  1. 開通する。申し込みのあとの開通は、自分で行います。選んだ SIM の種類によって手順が違います。
    • SIM カードの場合。届いた商品を受け取って、利用開始の設定をします。届くまで 1 週間前後かかることがあります。
    • eSIM（端末の中に入る電子的な SIM）の場合。「 eSIM 利用開始手続きのご案内」のメールが届いたら、設定をダウンロードして開通します。当日から 3 日前後で使い始められると案内されています（出典 2 ）。
    • eSIM は配送を待たずに済む分、早く始められますが、お手元の端末が eSIM に対応しているかは、第 2 章で確認してください。 SIM カードを選ぶと、届くのを待つことになります。
    eSIM を自分で削除しないでください。再発行が有料になる場合があります（出典 4 ）。開通の途中で分からなくなったら、 ahamo のチャットに相談します（第 6 章 7 番）。
  2. d アカウントの利用開始設定をする。開通した電話番号に SMS（電話番号あての短いメッセージ）が届きます。案内に沿って進めます（出典 2 ）。
  3. つながるか確かめる。電話と、インターネット（Wi-Fi を切って）を試します。
  4. d 払い・ iD を試す。第 5 章のとおりです。
  5. 請求を確認する。月額料金は、 NTT ファイナンスから請求されます（出典 4 ）。最初の請求書で、金額を確かめます。
  6. 旧契約のこと。ドコモのプランは、変更とともに ahamo に切り替わります。変更後の手続きは、ドコモショップなどではできず、 WEB または郵送で行います（出典 2 ）。
  7. 困ったとき。申し込みの方法が分からないときは、 ahamo のチャット、またはドコモのオンライン手続きサポートに相談します（出典 15 ）。契約後の相談は、お店では受けられません（出典 1 ）。
申し込みの画面が開かない場合は、 Google アプリや Yahoo! アプリの中から開いていないか確認してください。 iPhone は Safari 、 Android は Chrome の最新版で開くよう案内されています（出典 15 ）。

8詐欺・偽サイトに注意

携帯電話会社を名乗る電話・メール・ SMS ・メッセージには注意してください。暗証番号やパスワードは、誰にも口に出して伝えないでください。入力が必要なときは、ご自身の手で、画面をのぞかれないようにして入力します。

  • ドコモは、フィッシング詐欺（本物そっくりの偽サイトや偽メッセージで、 ID や暗証番号を盗む手口）への対策のページを設けています（出典 16 ）。助言
    「利用停止になる」「不正利用された」などと不安をあおる連絡には、あわてて返事をしない。
  • メールや SMS のリンクからは、ログインや手続きをしない。 ahamo サイトは、ブックマーク（お気に入り）から開く。助言
    理由は、偽サイトは本物に似た住所を使うからです。
  • お店の人にも、暗証番号を声に出して伝えない・紙に書かない。助言
  • だまされたかもしれないと思ったら、すぐに d アカウントのパスワードを変更し、ドコモの公式の案内（出典 16 のページから探せます）で対応を確認する。助言

まだ使っていない三つの機能 ― Research・Claude in Chrome・メモリ

日常的にお使いのチャット、Artifacts、Gmail連携、Claude Code に加えて、手をつけていない機能が三つあります。いずれも数分で使い始められます。

1. Research 2. Claude in Chrome 3. メモリ 使い分けの目安

1. Research （リサーチ）

一つの問いから自動で何度も検索を重ね、出典付きの長いレポートを書き上げる機能。所要は数分から。

  1. ウェブ検索をオンにするこれが前提条件です。オフのままでは Research は動きません。
  2. 入力欄の左下「+」をクリックし、「Research」を選ぶオンになるとチャット下部に青いインジケーターが出ます。もう一度押せば解除されます。
  3. そのまま質問を投げるあとは待つだけです。タブを開いたままにする必要はなく、別の作業に移って構いません。
  4. 出典を確認する本文の主張ごとに引用リンクが付くので、そこから原典に当たって裏を取ります。
向いている使い方 静的サイトジェネレーターの比較、各国の政策比較、業界の競合調査など「複数の情報源をまたいで一本の報告にまとめる」種類の問い。逆に、単発の事実確認や天気の照会には過剰です。Gmail などを連携していれば、ウェブと自分のメールを突き合わせた調査もできます。

2. Claude in Chrome

Chrome のサイドパネルから、いま開いているページを読ませたり、クリックや入力を任せたりできる拡張機能。

  1. Chrome ウェブストアから拡張機能を入れる「Claude」を検索し、「Chrome に追加」。Claude のアカウントでサインインします。
  2. デスクトップアプリ側で有効にする左下のイニシャル →「設定」→ コネクターの一覧から Claude in Chrome をオンに。
  3. ツールバーの Claude アイコンでサイドパネルを開く閲覧中のタブの内容は、追加設定なしで読み取られます。
  4. やってほしい作業を書く操作のたびに許可を求められます。「この操作だけ許可」が最も安全、「このサイトでは常に許可」は信頼できるサイトに限ります。
  5. 許可の棚卸しサイドパネル右上の三点メニュー →「拡張機能の設定」で、常に許可したサイトの一覧を確認・取り消しできます。
注意点 ページに仕込まれた指示で Claude が誤作動する「プロンプトインジェクション」の危険があります。機密情報を表示している間は開かない、金銭が動く操作は必ず自分で確認する、専用のブラウザープロファイルを分ける ― この三つを守ってください。なお Chrome 専用で、他の Chromium 系ブラウザーやモバイルでは動きません。金融・暗号資産系サイトは既定でブロックされています。
想定される出番 XServer やお名前系の管理画面、GitHub の Settings 画面など「読み取って確認する」作業。DNS レコードの現状を一覧で読ませて計画書と突き合わせる、といった使い方が現実的です。

3. メモリ（記憶）の管理

プロジェクトの文脈が引き継がれているのはこの機能のおかげです。中身は自分で読めますし、書き換えられます。

  1. 中身を見る「設定」→「機能 (Capabilities) 」→「メモリを表示・編集」。記憶している内容が一覧で出ます。
  2. チャットから直接足す・消す会話の途中で「これを覚えておいて」「あれは忘れて」と言えば、その場で更新されます。設定画面を開く必要はありません。
  3. 書き出して保管する「記憶している内容を、そのままの形で書き出して」と頼めば全文が出ます。Obsidian の Vault に貼っておけばバックアップになります。
  4. ときどき棚卸しする古い前提が残っていると誤った回答の元になります。半年に一度でも見直す価値があります。
ひとこと サイト移行のように何日もまたぐ仕事では、決定事項をこちらから明示的に「覚えておいて」と伝えておくと、次のセッションの立ち上がりが目に見えて速くなります。

使い分けの目安

やりたいこと使うもの
事実を一つ確かめたい通常のチャット（ウェブ検索）
複数の情報源をまとめた報告がほしいResearch
いま開いている画面を読ませたい・操作させたいClaude in Chrome
長期の仕事の前提を引き継ぎたいメモリ
手元のファイルを実際に書き換えたいClaude Code （すでに活用中）
